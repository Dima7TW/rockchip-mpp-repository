# Rockchip-MPP-Repository
Repository deb packages with RKMPP support (beta, in development).
Not recommended for production at the moment.

# About this repository
This repository have:
-Ffmpeg 7.1.5 (by nyanmisaka);
-Rockchip librga 1.10.4;
-Rockchip MPP (latest);
-MPV 0.38;
-Celluloid 0.27 (ubuntu noble) / 0.30 (debian trixie);
-OBS-studio 32.0 (by MecoMedia);
-Moonlight 6.1.0 (latest);
-V4L-utils (1.30).
There are plans to add:
-gstreamer (1.28, 1.24 already exists, may be added or updated);
-chromium (132+);
-kodi (21+).
